# لوحة أبونابت لإدارة الروابط

هذه خدمة مستقلة بواجهة عربية لإدارة روابط Shlink ورموز QR وإحصاءات الزيارات. تتصل بالخادم من الخلفية فقط، ولذلك لا يصل مفتاح Shlink إلى متصفح المستخدم.

## النشر في Coolify

أنشئ **خدمة جديدة** من المستودع نفسه، واضبط مسار Dockerfile على `dashboard/Dockerfile` ومسار البناء على `dashboard`. اربط الخدمة بالنطاق `app.qrcode.abothabet.com`، ثم أضف متغيرات البيئة التالية داخل إعدادات الخدمة:

| المتغير | القيمة |
|---|---|
| `SHLINK_BASE_URL` | `https://qrcode.abothabet.com` |
| `SHLINK_API_KEY` | مفتاح API بصلاحيات إدارة الروابط والزيارات والوسوم |
| `ADMIN_PASSWORD` | كلمة مرور طويلة خاصة بلوحة الإدارة |
| `SESSION_SECRET` | قيمة عشوائية طويلة لا تقل عن 32 محرفًا |
| `PORT` | `3000` |

يجب عدم وضع `SHLINK_API_KEY` في ملفات الواجهة أو داخل Git. بعد ضبط المتغيرات، نفّذ النشر ثم اختبر تسجيل الدخول من النطاق الجديد.

## التشغيل المحلي

انسخ القيم السابقة إلى متغيرات بيئة محلية ثم نفّذ:

```bash
npm install
npm run dev
```

يُشغّل الأمر الخادم والواجهة على المنفذ `3000`.
